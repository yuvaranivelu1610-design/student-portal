# 🎓 Student Portal

A simple and user-friendly web-based Student Portal developed using HTML, CSS, and JavaScript.

The Student Portal provides students with a centralized platform to view their academic and personal information through different modules such as Dashboard, Profile, Courses, Attendance, and Marks.

---

## 📌 Project Overview

The main purpose of this project is to design and develop a simple Student Portal that organizes important student information in one place.

The application contains multiple web pages connected through a common navigation system. Students can easily move between different sections and view their academic details.

This project demonstrates the use of front-end web development technologies to create a structured and interactive student management interface.

---

## ✨ Features

- 🔐 Student Login
- 🏠 Student Dashboard
- 👤 Student Profile
- 📚 Course Information
- 📅 Attendance Details
- 📊 Marks and Academic Performance
- 🔗 Navigation Between Different Pages
- 💻 Simple and Responsive User Interface
- ⚡ Easy to Use and Understand
